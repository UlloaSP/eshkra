Scope: eshkra.dev home page (`src/pages/index.astro`), shared layout and 404. Visitor mode: Persuade (discovery).

Audience: ML researchers and developers, equally. Job: discover every eshkra project, see how they connect, and leave for the right repository, docs site or the running MLSuite app. Proof: live stars, downloads and versions, real README snippets, the public MLSuite instance. Constraints: static, zero JS by default, truthful copy from `src/data/products.ts` and the READMEs, theme follows the system, phone and desktop. User-ruled-out: generic AI-startup glow, academic, heavy animation, SaaS template, and the earlier printed-form direction.

Memorable moment: the four product marks as a family on the hero, joined by one path, then each product opening into its own panel with real code.

## Direction contract

THESIS: The category standard for a multi-product open-source company, executed at the craft level of voidzero.dev, hashicorp.com, astral.sh and tanstack.com. One umbrella brand, four products that each feel like a product.

OWN-WORLD: Neutral white or near-black ground following the system; eshkra's ember orange (from the eshkra mark the user supplied mid-build, which replaced the earlier violet accent) for the headline's key phrase, focus and selection, with a near-black (light) or near-white (dark) primary button; the product marks (graphite ribbons around an ember orb, the eshkra material) as the only rich imagery, each product owning one warm hue for its tile shadow and connector. Mona Sans (GitHub's open-source face) for everything; JetBrains Mono for code and small technical labels. Soft 12px radii, hairline borders, no hard shadows.

STORY: The visitor reads what eshkra makes, sees the four marks joined from trained model to reviewed prediction, scans the live numbers, picks a library or the application from the family index, reads its panel with real code, and leaves for docs, GitHub or the app.

FIRST VIEWPORT: Slim nav (wordmark, Projects, GitHub, Try MLSuite); centred headline with the key phrase in eshkra ember; one-line lede; primary "Explore the projects" and secondary "Try MLSuite"; below it the four marks as app-icon tiles connected by one path line with step labels. A TanStack-style live metrics strip closes the viewport.

FORM: Canon (the category standard), chosen by the user from the round seeded 28aeb364, with VoidZero and HashiCorp as the named references and Astral and TanStack as the bar. Seed key 28aeb364 is the key printed by the concept-seed roll for this round. Signature interaction: the product rail beside the panels highlights the panel in view through CSS scroll-driven timelines, with all items equal where unsupported; no JavaScript.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
